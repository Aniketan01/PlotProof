# 🏛️ PlotProof
### Land Ownership Transfer & Statutory Document Verification System

**PlotProof** is a transparent, digital land conveyance portal designed under the Karnataka Land Revenue & Title Registration framework. It allows buyers, sellers, and sub-registrar officers to execute title transfers, upload statutory deeds, cross-reference cadastral survey numbers, and audit immutable transaction logs.

---

## 👥 Key User Roles
- **Citizen Buyer:** Registers with Aadhaar/PAN, submits land purchase requests, calculates 7% statutory stamp duty, uploads sale deed & EC documents, and tracks verification milestones.
- **Landowner Seller:** Confirms conveyance agreements, uploads seller identity proofs, and certifies title ownership against cadastral survey records.
- **Sub-Registrar Officer / Admin:** Reviews flagged document discrepancies, validates surveyor demarcations and tax clearances, and issues final conveyance approvals.

---

## 📄 7 Statutory Documents Verified
1. **Buyer ID Proof (Aadhaar / PAN)** — Format and identity validation.
2. **Seller ID Proof** — Name spelling and cadastral registry match.
3. **Sale Deed / Title Deed** — Chain of title and legal ownership certification.
4. **Encumbrance Certificate (EC)** — Nil mortgage lien and court litigation check.
5. **Property Tax Receipt** — Validates municipal property tax is paid up to date.
6. **Khata / RTC / Survey Records** — Confirms plot survey number and acre/sq.ft demarcations.
7. **Sale Agreement** — Validates parties, consideration value, and payment terms.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- Git

### Installation
```bash
# Clone the repository
git clone https://github.com/Aniketan01/Land-Ownership-Transfer.git
cd Land-Ownership-Transfer

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
